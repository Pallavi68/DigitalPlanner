Production hosting for Vite and Supabase

Key findings

Vercel supports Vite directly, but React Router deep links need an SPA rewrite to /index.html.
The build needs only the public Supabase URL and publishable/anon key as Vite environment variables; no service-role or database password belongs in hosting configuration.
Supabase Auth Site URL must become the exact permanent HTTPS production URL. Production redirect URLs should be exact; wildcards are more appropriate for controlled preview URLs.
After deployment, magic-link, direct dated routes, refresh, cross-device sync, offline recovery, and Realtime invalidation require live testing.
