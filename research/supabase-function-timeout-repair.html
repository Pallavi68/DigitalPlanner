Supabase function timeout repair

Key findings

Supabase's authenticated REST role has an 8-second default statement timeout.
Supabase explicitly supports function-level statement_timeout settings for recurring functions called through its client REST API.
For this single-owner planner, a bounded 30-second exemption on only save_planner_state is narrower than changing the database-wide or authenticated-role timeout.
Long-term optimization should replace full aggregate writes with smaller changed-day mutations, but the scoped timeout safely restores current functionality without broad configuration changes.
